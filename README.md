# 🛍️ GARMS — Thrift Streetwear E-Commerce Website

GARMS is a thrift streetwear e-commerce website developed as a university project.

The website provides an online shopping experience where users can browse streetwear products, view product details, select sizes and quantities, add products to their cart, manage their wishlist, and explore different product categories.

---

## 📌 Project Overview

GARMS was developed as a full-stack web application combining a modern frontend with an ASP.NET Core backend and Microsoft SQL Server database.

The project demonstrates:

- Frontend web development
- Backend development
- Database integration
- REST API development
- Product management
- E-commerce functionality
- Responsive web design

---

# ✨ Features

### 🛍️ Product Browsing
- Browse available streetwear products
- Browse products by category
- View product information
- View product images and prices

### 👕 Product Details
- View individual product pages
- Select available sizes
- Select product quantity
- Add products to cart
- Add products to wishlist

### 🛒 Shopping Cart
- Add products to cart
- Select product quantities
- View selected products
- Manage cart items

### ❤️ Wishlist
- Add products to wishlist
- Remove products from wishlist
- View saved products

### 🗄️ Database
- Microsoft SQL Server integration
- Product information stored in a database
- Product information retrieved through the backend

### 🔌 API
The project includes API endpoints for retrieving product information and checking the server status.

### 📱 Responsive Design
The website is designed to work across different screen sizes and devices.
